What was being tested?

Jamie was an AI-generated adviser identity. The numerical advice was set by the experiment rather than by the model seeing the dot images.

The full study uses three advice conditions: neutral wording, persuasive wording, and adaptive persuasive wording. In the full schedule, each condition contains six recommendations above the true count and six below it. For a given participant, the same dot count had the same UP or DOWN recommendation across all three conditions, so the numerical advice was matched when comparing the wording conditions.

In the adaptive persuasive condition, Jamie could use your earlier completed decisions and trust ratings{% if rating_items=='trust_and_feeling' %} and feeling ratings{% endif %} from that condition to shape later messages. Neutral and persuasive messages did not receive that response history. The current first estimate was not provided to the model before its message was generated.

The study asks whether persuasive wording changes advice-taking, and whether persuasion that adapts to a participant's earlier responses changes it further.
