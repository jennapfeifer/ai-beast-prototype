Three synthetic participants each complete all 36 experimental trials. Messages come from the selected live adviser; all three conditions use the selected live adviser model.

This makes 108 generated-message requests before retries (up to 324 provider attempts with the default three-attempt policy). API charges apply. Keep this page open and do not run another pilot in this browser while it runs.

Response-neutral audit: the computer is not assigned a resistant, receptive, or changing profile. Its final estimates vary deterministically from trial to trial using a condition-blind rule, and the same participant/numerosity pair gets the same latent response tendency in Neutral, Persuasive, and Adaptive. Trust ratings are generated independently. The simulator never reads the adviser wording when choosing the final estimate.

This therefore tests message generation and adaptive grounding only. It cannot tell you whether persuasive wording actually changes advice-taking; that requires human participants.
